Files and Folders in this folder will be synced to NEPI's source-code build folder (/mnt/nepi_storage/nepi_src/nepi_engine_ws/src), then used during NEPI's build processes on top of NEPI's defualt source-code files. 

Only keep files here that this repo actually changes. Every build copies them over the engine's own copies with no staleness check, so an unmodified copy of an engine file silently reverts the engine to whatever version was copied, and breaks the build or the running system once the engine moves on. On 2026-09-28 stale copies of the engine's nepi_api, nepi_interfaces, and RUI files crashed system_mgr against an updated engine and were removed; what remains of those folders here (nepi_api/device_if_rbx.py and the RBX/Store RUI pages) has real drone changes and must be merged onto the engine's current version whenever the engine updates. src/nepi_engine is never copied (no matching build symlink) and is inert.
