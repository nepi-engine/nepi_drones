# sim_old_plan

Archived, not deleted. `app_sim_connector/` here is this repo's own Phase 1/2 attempt at
`device_if_sim.py` + `sim_connector_node.py` (built and fully tested 2026-08-04) — see
`docs/SIMULATION_INTERFACE_SPEC.md` for the full history.

**As of the 2026-08-05 team meeting, the generic `device_if_sim.py` contract implementation
is owned by the NEPI-core team, not this repo.** This folder exists so that work isn't lost
or in the way while their version gets built — they may push over some of it and run on top
of it, or replace it entirely. Nothing here is the active plan; don't build on it. See
`docs/SIMULATION_INTERFACE_SPEC.md`'s top-of-document decision note and its Implementation
Plan's "Superseded 2026-08-05" banner for current direction.
